Software

Why is software so important?

There are many key pieces of software we must create for our mission. Every electrical component needs to be incorperated into the code, and multiple programmes have to be writen for multiple jobs.

Data transmission:

We are using a radio to transmit data from the can, to our ground station. The programme will allow comunication between a transmitter and reciever, so the data can be sent. It also makes the data readily accesible to be accesed.

Collection of primary and secondary data:

We are using a thermometer, and pressure sensor, the data from these is sent to the transmitter, then to the ground station.
We also have a spectroscoper, which can give us a rough soil profile. We will be able to pick up traces of biological entities, organic carbon containing matter, iron based compounds, and soil moisture levels. The programme needs to decode all the data from this component into something we can read and analyse.
